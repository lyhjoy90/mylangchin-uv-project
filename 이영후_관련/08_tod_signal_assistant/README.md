# 08. 지자체 교통신호 민원 분석 & TOD 조정 권고 AI (TOD Signal Assistant)

교차로 정체 및 꼬리물기 관련 시민 민원 텍스트를 분석하여 정체 발생 시간대와 대상 교차로를 파악하고, 경찰청/국토교통부 신호운영 편람 지침에 근거한 TOD(Time of Day) 신호값(녹색시간 연장, Offset 연동값, All-Red 조정 등) 및 대민 답변서를 자동 작성하는 AI 솔루션입니다.

---

## 📌 주요 특징 (Key Features)

1. **교통신호 민원 텍스트 정밀 파싱**
   - 거친 민원 문장에서 대상 교차로명, 시간대(출퇴근/주말), 정체 방향(좌회전/직진 등) 자동 추출.
2. **신호운영 편람 연동 TOD 신호 조정안 제안**
   - 좌회전 녹색시간(+3~5초), 연동값(Offset) 재설정, All-Red(전적신호) 연장 등 공학적 개선안 제시.
3. **공식 대민 민원 답변글 원스톱 자동 생성**
   - 행정 공문서 및 지자체 민원게시판용 친절하고 표준화된 대민 답변글을 일괄 작성.

---

## 🎯 1. 프로젝트 목적 (Purpose)

1. **교통신호 민원 처리 시간 단축 및 신호 운영 효율화**
   - 접수된 신호 민원 분석부터 신호 조정안 산정 및 대민 답변 작성까지의 행정 절차 단축.
2. **교통공학 지침(경찰청 신호운영 편람) 기반의 정밀 조정**
   - 담당자의 경험적 판단을 넘어 표준 신호운영 편람 지침 수치에 근거한 조정 권고.
3. **지자체 교통정보센터 신호운영 실무 지원**
   - Gunsan 및 지자체 도시통합센터 신호운영 용역 및 담당자의 업무 생산성 향상.

---

## 💡 2. 추진 배경 (Why)

1. **교차로 정체 및 꼬리물기 시민 민원의 높은 비중**
   - 출퇴근 시간대 특정 교차로 대기행렬 침범 및 보행시간 부족으로 인한 민원이 지속 발생.
2. **현장 TOD 신호 주기 조정 시 표준 가이드라인 인용 필요성**
   - 신호 시간을 무작위로 변경할 경우 연동된 주간선도로 전체의 신호 연동(Offset)이 파괴될 위험 존재.
3. **감정적 민원 문장에 대한 정형화된 행정 답변 도구 부재**
   - 민원인의 격앙된 문장에 맞춰 공식적이고 친절한 행정 답변글을 즉시 작성해 주는 도구 필요.

---

## ⚠️ 3. 문제점 (Problems Addressed)

1. **민원 내용에서 핵심 신호 파라미터 추출의 어려움**
   - "차가 너무 막힌다"는 식의 추상적 표현에서 구체적 방향(좌회전/직진)과 시간대 수동 도출 한계.
2. **신호 시간 변경 시 교차로 간 연동성(Offset) 고려 누락**
   - 단일 교차로 녹색시간만 수정한 후 주변 교차로와의 연동이 깨져 이차 정체 유발.
3. **민원 답변서 작성 시 공학적 인용 근거 부족**
   - 단순히 "검토하겠다"는 식의 상투적 답변으로 인한 민원인의 불만 지속.

---

## 🛠️ 4. 개선안 (Solutions Provided)

1. **경찰청 교통신호운영 편람 FAISS RAG 인덱싱**
   - 보행속도 기준(0.9m/s), 꼬리물기 대응 All-Red 기준, TOD 연동 기준을 벡터화하여 최적 조율.
2. **3단계 통합 출력 구조(원인분석 -> TOD 권고안 -> 대민 답변서)**
   - 한 번의 입력으로 공학적 원인 분석부터 신호값 조정 제안, 시민 답변서까지 완벽 분리 작성.
3. **Gradio UI 기반 시연 인터페이스 제공**
   - 신호 운영 담당자가 민원 입력 후 생성된 조정안을 즉시 확인 및 복사할 수 있는 대시보드 구동.

---

## 🚨 5. 한계점 (Limitations)

1. **현장 VDS/정류장 수집 실시간 교통량 데이터 직접 API 연동 미비**
   - 텍스트 민원 분석 중심이며, 실시간 VDS 검지기 차두 시간 데이터와의 Real-time API 연동은 미포함.
2. **신호제어기(Local Controller)에 대한 신호값 자동 입력 제약**
   - 본 시스템은 권고안 및 답변서 작성 도구이며, 현장 신호제어기 직접 통신 제어 기능은 보안상 미적용.
3. **복잡한 다지교차로(5지 이상)의 특수 신호 연동 계산 한계**
   - 표준 4지 교차로 위주 편람 적용으로 특수 구조 교차로는 담당자 최종 검토 병행 필요.
4. 교통신호기 관련 편람 다운로드 문제로 요약본 txt 사용
공식 대용량 신호운영 편람 PDF의 원문 직접 연동 한계로 인해 핵심 요약 텍스트를 대체 사용함에 따라, 제어기 제조사별 특수 규격이나 방대한 예외 사례 조항 전체를 심층적으로 커버하는 데는 한계가 존재함.
